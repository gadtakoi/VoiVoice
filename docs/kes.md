Разберу пошагово, как добавить исключение для микрофона для Python‑скрипта в Kaspersky Endpoint Security.

Способ 1. Через интерфейс приложения (на локальном компьютере)
Откройте Kaspersky Endpoint Security.

Нажмите на значок шестерёнки (Настройки) в нижнем левом углу главного окна.

В меню настроек выберите раздел «Общие».

Найдите и откройте пункт «Исключения и типы обнаруживаемых объектов».

Перейдите по ссылке «Настроить исключения» — откроется окно со списком текущих исключений.

Нажмите кнопку «Добавить», чтобы создать новое исключение.

В открывшемся окне выберите один из вариантов:

«Файл или папка» — если нужно исключить конкретный скрипт или папку с скриптами;

«Процесс» — если требуется исключить Python‑интерпретатор (например, python.exe или pythonw.exe) из проверки.

Если выбрали «Файл или папка»:

Нажмите «Обзор» и найдите Python‑скрипт, который использует микрофон.

Либо вручную введите путь к файлу или папке. Можно использовать маски:

* — заменяет любые символы (например, C:\Scripts\*.py исключит все Python‑скрипты в папке Scripts);

? — заменяет один любой символ.

Если выбрали «Процесс»:

Введите имя исполняемого файла (например, python.exe) или полный путь к нему.

В блоке «Компоненты защиты» отметьте, для каких модулей Kaspersky будет действовать исключение:

Файловый антивирус — если скрипт или процесс блокируется при запуске;

Контроль устройств — критично для доступа к микрофону;

Сетевой экран — если проблема связана с сетевым взаимодействием;

Или выберите «Все компоненты», если не уверены.

При необходимости добавьте комментарий (например, «Скрипт для записи звука с микрофона»).

Убедитесь, что статус исключения установлен как «Активно».

Нажмите «Добавить», затем «ОК» для сохранения настроек.
