# Changelog

## 0.1.0 — 2026-05-20

### Added
- Initial MVP release
- Docker Compose orchestration (ASR, LLM, API Gateway)
- Windows client with system tray
- Global hotkey (Ctrl+Alt+V) with hold-to-record
- Audio capture with sounddevice
- Silero VAD integration (ONNX)
- ASR via faster-whisper (CPU, INT8)
- LLM cleanup via Ollama (llama3.2)
- Text injection via SendInput / clipboard fallback
- Audio beacons (start/stop/success/error tones)
- Timing logs for performance analysis
- Windows toast notifications
- Configurable via config.yaml
- Extensive documentation
